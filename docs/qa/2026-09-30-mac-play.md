## Defect found and fixed

`deploy/devnet.sh` took any `starknet-devnet` on `PATH` as installed. On this Mac asdf has the plugin's shim for
`starknet-devnet`, and the shim refuses to run: `No version is set for command starknet-devnet` (the pin of
`ASDF_STARKNET_DEVNET_VERSION` is not honoured by this asdf), so `up` waited 2 minutes for a devnet that never
started. Fix: a binary counts as installed only if `starknet-devnet --version` runs; otherwise the release binary is
downloaded into `deploy/.devnet/bin/` (first on `PATH`), as on a machine without asdf's plugin.

## The caller's environment

No `local mode: ignoring your ...` line (`scripts/play.sh` prints it when `STARKNET_*`, `SLINGFALL_*`, `ATLANTIC_*`,
`VITE_*` or `DEVNET_*` variables are set) appeared in any `up` of this run, so this shell held none: the ignoring of
`STARKNET_*` was not exercised on the Mac, and no `STARKNET_*` variable was read or set by this lot.
